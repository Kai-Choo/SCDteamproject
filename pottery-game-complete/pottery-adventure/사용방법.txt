3D 토기 맞추기 게임

실행: 이 폴더의 index.html을 Chrome 또는 Edge로 여세요.
START → 토기 선택 → 조각 맞추기 순서로 이동합니다.
별도 설치나 인터넷 연결이 필요하지 않습니다. WebGL 지원 브라우저를 사용하세요.
폴더 전체를 함께 전달하세요. HTML만 따로 옮기면 이미지와 페이지 이동이 끊어집니다.

제기형 토기 / 공렬토기(구멍무늬토기)는 각각 새로 제작한 7조각 모델을
사용합니다. 불규칙한 미세 요철, 옅은 색 변화와 드문 긁힘을 적용했습니다.
공렬토기는 커진 원형 구멍, 제기형 토기는 낮아진 바닥 분리선을 사용합니다.
게임 이름과 페이지, 모델 파일은 각각 분리되어 있습니다.

소스 수정/모델 교체
함께 제공되는 소스의 games/jegi와 games/gongryeol 폴더를 각각 수정하세요.
각 폴더의 assets/pottery.glb를 교체할 수 있습니다.
교체 모델은 Pottery_Base, Pottery_Piece_01~06의 7개 오브젝트를 유지하고,
각 오브젝트는 완성 위치와 이동 중심을 가진 상태로 내보내야 합니다.
원본 예시 모델과 동일한 Y-up, 미터 단위, 크기 기준을 사용하세요.
소스는 로컬 웹서버 또는 기존 게임 서버에서 실행하세요.

이 전달용 버전의 게임 HTML은 코드·라이브러리·모델을 내장한 실행본입니다.
소스 수정 후에는 실행본을 다시 생성해야 변경 내용이 반영됩니다.

화면 디자인
시작 화면과 선택 화면은 승인된 이미지 위에 클릭 가능한 링크를 배치했습니다.
선택 화면의 배경 불투명도는 위아래 경계선 없이 동일하게 적용했습니다.
왼쪽 위 나무판형 홈 버튼을 누르면 시작 화면으로 이동합니다.
